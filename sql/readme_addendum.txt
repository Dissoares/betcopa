O sistema já possui integração com API-Football (api-sports.io) para importar jogos e sincronizar resultados.

Configuração:
- Editar src/config.php
- Inserir chave em api_football.key

Uso:
- Painel admin > Importar Jogos
- Painel admin > Sincronizar Resultados

A importação é gratuita se você usar a chave grátis do api-sports.io, respeitando os limites do plano.
